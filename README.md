# 🏦 Bank Customer Churn Analysis | Python & Tableau

## 📌 Project Overview

Customer retention is a major challenge in the banking industry. Understanding why customers leave can help financial institutions improve customer satisfaction and develop effective retention strategies.

This project presents an end-to-end data analytics study of bank customer churn using **Python for data cleaning and Exploratory Data Analysis (EDA)** and **Tableau Public for interactive data visualization**.

The analysis explores customer demographics, geographical distribution, account activity, product ownership, and account balances to identify patterns associated with customer churn.

## 🎯 Project Objectives

- Analyze overall customer churn and retention rates.
- Identify customer segments with higher churn rates.
- Explore the relationship between customer demographics and churn.
- Examine how customer activity and product ownership relate to retention.
- Compare account balance distributions between retained and churned customers.
- Present findings through an interactive Tableau dashboard.

## 📂 Project Workflow

1. **Data Collection:** Obtained the bank customer churn dataset.
2. **Data Cleaning:** Removed unnecessary columns, prepared the dataset, and created meaningful categorical features.
3. **Feature Engineering:** Created age groups and a customer churn status variable (Retained/Churned).
4. **Exploratory Data Analysis:** Investigated six key dimensions of customer churn using Python.
5. **Data Visualization:** Recreated key analytical insights in Tableau.
6. **Dashboard Development:** Designed an interactive dashboard to communicate findings.

## 📊 Exploratory Data Analysis

The project focuses on six key analytical areas:

### 1. Overall Customer Churn
Analyzed the proportion of retained and churned customers to understand the overall customer retention situation.

### 2. Churn by Age Group
Examined churn patterns across different age groups to identify customer segments with higher attrition.

### 3. Churn by Geography
Compared customer churn across geographical regions to identify regional differences in retention.

### 4. Churn by Activity Status
Investigated the relationship between customer account activity and churn behavior.

### 5. Churn by Number of Products
Explored whether the number of banking products held by customers is associated with their likelihood of leaving.

### 6. Account Balance and Churn
Compared account balance distributions between retained and churned customers using a box-and-whisker plot.
